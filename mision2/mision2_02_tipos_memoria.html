Corto Plazo
Duración: segundos a minutos

Almacena información de forma temporal mientras la usas en el momento. Tiene una capacidad limitada — el cerebro puede retener aproximadamente 7 ± 2 elementos a la vez. Es el primer filtro antes de decidir qué vale la pena guardar.

// Ejemplo

Recordar un número telefónico el tiempo suficiente para marcarlo, sin haberlo guardado antes.

TAP PARA VER →
Largo Plazo
Duración: días, años o toda la vida

Es la gran "biblioteca" del cerebro — con capacidad casi ilimitada. Se consolida principalmente durante el sueño, cuando el hipocampo transfiere recuerdos a la corteza cerebral para almacenamiento permanente. Se divide en declarativa (hechos y eventos) y procedimental (habilidades).

// Ejemplo

Recordar el nombre de tu primera escuela, cómo andar en bicicleta o las tablas de multiplicar.

De Trabajo
Activa durante tareas complejas

Es la "pantalla mental" donde manipulamos información activamente para razonar y resolver problemas. Controlada principalmente por la corteza prefrontal, es clave para el aprendizaje académico: permite sostener una idea mientras procesas otra, como leer un enunciado y calcular al mismo tiempo.

// Ejemplo

Resolver 47 + 38 mentalmente: guardas el 7 mientras sumas las decenas y luego combinas el resultado.
